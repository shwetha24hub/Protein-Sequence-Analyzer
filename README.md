# 🧬 Protein Sequence Analyzer

A bioinformatics web application developed using Python, Biopython, and Streamlit to analyze protein sequences and calculate important protein properties.


## ✨ Features

* Accepts protein sequences as input.
* Validates standard amino acid sequences.
* Calculates protein length.
* Calculates molecular weight.
* Estimates theoretical isoelectric point (pI).
* Displays amino acid composition in a table.
* Visualizes amino acid composition using a bar chart.

## 🛠️ Technologies Used

* Python
* Biopython
* Streamlit
* Pandas

## 🧪 Sample Input

MKWVTFISLL


## 📊 Results

The application displays:

* Protein length
* Molecular weight in Daltons (Da)
* Theoretical isoelectric point
* Amino acid counts
* Amino acid composition chart
